# Reports

Thư mục này chứa báo cáo, biểu đồ và bảng kết quả của dự án.

## Báo cáo

| Tệp | Nội dung |
|---|---|
| `final_report.md` | Nội dung đầy đủ của báo cáo cuối kỳ |
| `01_data_quality_report.md` | Rút gọn, kiểm tra chất lượng và làm sạch dữ liệu |
| `02_eda_report.md` | Phân tích khám phá cho RQ1 đến RQ5 |
| `03_ml_readiness_report.md` | Chuẩn bị dữ liệu cho mô hình |
| `04_modeling_report.md` | Hồi quy và phân loại |
| `05_model_evaluation_report.md` | Đánh giá mô hình |
| `06_statistical_inference_report.md` | Xác suất, kiểm định, phân tích kiểu A/B |
| `07_big_data_ethics_bias_report.md` | Big data, đạo đức, thiên lệch |

Bản Word (`Bao_cao_cuoi_ky_GameStream.docx`, `Bao_cao_giua_ky_GameStream.docx`) không đưa lên GitHub. Số liệu trong báo cáo cuối kỳ thay thế số liệu tương ứng ở báo cáo giữa kỳ (xem mục 1.6).

## Thư mục con

- `figures/`: biểu đồ lấy từ notebook, đặt tên theo số notebook, ví dụ `02_06.png` là hình thứ 6 của notebook 02.
- `tables/`: các bảng kết quả dạng CSV, do các notebook tạo ra.
